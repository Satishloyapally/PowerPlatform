# Automate Project Assignment Notifications

This project automates the process of notifying employees about new project assignments using Microsoft Power Platform.

## Project Structure
- **PowerAutomate**: Contains the flow definition JSON file.
- **Dataverse**: Contains the schema for the Dataverse table.
- **PowerApps**: Contains Power Apps project files.
- **PowerPages**: Contains HTML files for Power Pages.
- **JavaScript**: Contains JavaScript code to enhance Power Apps.
- **Python**: Contains Python scripts for integration.
- **PowerBI**: Contains Python scripts to generate Power BI reports.

Automate Project Assignment Notifications
Power Automate Flow:

Use Case: Notify employees about project assignments.
Explanation: This flow triggers when a project is assigned and sends notifications to employees.
Dataverse Schema:

Use Case: Store project assignment data.
Explanation: The schema includes fields for employee name, email, project name, and assignment date.
Power Apps:

Use Case: Manage project assignments.
Explanation: Power Apps provides an interface for managing project assignments.
Power Pages:

Use Case: Employee portal for project details.
Explanation: A web page allows employees to check their project assignments.
JavaScript:

Use Case: Customize notifications.
Explanation: A script sends customized notifications about new project assignments.
Python:

Use Case: Send project assignment notifications.
Explanation: A Python script sends email notifications about new project assignments.
Power BI:

Use Case: Track project assignments.
Explanation: Dashboards track project assignments, deadlines, and employee workload.
