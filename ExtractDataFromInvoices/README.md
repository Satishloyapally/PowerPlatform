# Extract Data from Invoices

This project automates the extraction of data from invoices using Microsoft Power Platform.

## Project Structure
- **PowerAutomate**: Contains the flow definition JSON file.
- **Dataverse**: Contains the schema for the Dataverse table.
- **PowerApps**: Contains Power Apps project files.
- **PowerPages**: Contains HTML files for Power Pages.
- **JavaScript**: Contains JavaScript code to enhance Power Apps.
- **Python**: Contains Python scripts for integration.
- **PowerBI**: Contains Python scripts to generate Power BI reports.

Extract Data from Invoices
Power Automate Flow:

Use Case: Extract and store invoice data.
Explanation: This flow uses AI Builder to extract data from invoices and store it in Dataverse.
Dataverse Schema:

Use Case: Store extracted invoice data.
Explanation: The schema includes fields for invoice number, amount, date, and supplier name.
Power Apps:

Use Case: Review and approve invoices.
Explanation: Power Apps provides an interface for reviewing and approving extracted invoice data.
Power Pages:

Use Case: Web interface for invoice management.
Explanation: A web page allows finance teams to manage invoice data.
JavaScript:

Use Case: Validate invoice data.
Explanation: A script validates invoice amounts before processing.
Python:

Use Case: Extract and store invoice data.
Explanation: A Python script uses an AI Builder API to extract data and store it in Dataverse.
Power BI:

Use Case: Analyze invoice data.
Explanation: Dashboards analyze invoice data, monitor processing times, and identify trends.
